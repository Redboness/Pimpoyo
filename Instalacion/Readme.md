# Instalación

Debes tener instalado PostgreSQL. Te pedirá la contraseña de administrador para
hacer todos los cambios en la base de datos.

Abre una terminal en esta carpeta y ejecuta install.bat.

`.\install.bat`

**Solo tienes que hacerlo una vez.**

El resto de cosas debería instalarlas la terminal.

Una vez hecho, puedes volver a la carpeta principal y ejecutar start.bat en una terminal

`.\start.bat`
